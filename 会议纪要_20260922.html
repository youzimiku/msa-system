MSA系统原型评审会议纪要

会议时间：2026-09-22 11:37 ~ 12:37（约52分钟）
参会人：张会娟、高国翔
会议主题：MSA测量系统分析原型逐页评审（GRR/KAPPA/线性偏倚/稳定性/Cg/Cgk录入页 + 报告页 + 特性方法维护）

一、会议结论概览

本次会议逐页评审了五个录入数据页面、MSA计划创建弹窗、特性方法维护、报告页样式。核心结论：
1. 五个录入页统一改为左侧台账卡片列表 + 右侧录入矩阵布局，去掉下拉选台账；
2. GRR样本号扫描录入（可编辑、默认空、校验样本库），KAPPA样本号只读带出；
3. 稳定性加"组内次数"字段，决定实测值列数；
4. 保存和录入完成合并为"提交"，不做行级保存；
5. 报告图表直接复用丁宁（Minitab）和石洋洋（稳定性）的现成图，每图上方加统一表头；
6. 待确认项：提交后状态控制、编辑权限（需跟万工确认）。

三、需与万工确认的事项（张会娟明确要求对齐）

背景：本次会议评审录入页交互时，张会娟多次指出"数据提交后能不能改、谁能改、什么状态下能改"这些问题在原型里还没定义清楚，必须找万工（业务方）确认后才能写进开发备注，否则开发无法判断编辑模式的开启条件和权限边界。以下逐项列出：

问题1：数据提交后是否允许二次提交 / 修改？

维度说明
现状原型里"提交"按钮点击后，数据整体提交进入下一阶段（待分析）。但提交后录入人如果发现录错了，能不能回来改？目前没定义。
张会娟的顾虑"我都开始分析了，你还改数据"——如果已经进入分析阶段，数据被改了，分析结果就对不上。
需要万工确认① 提交后、分析前，录入人能不能改？② 分析已经开始了，还能不能改？③ 改了之后要不要重新触发分析？

问题2：提交后谁还有修改权限？

维度说明
现状原型里默认所有人都能编辑。会议讨论到：录入人提交完就不应该再能改，但责任人可能需要改。
张会娟的意见录入人录完提交后，原则上不能再改；如果确实要改，只有责任人有权限。但"责任人能不能改、改到什么程度"需要业务确认。
需要万工确认① 录入人提交后是否只读？② 责任人是否有修改权限？③ 其他角色（如质量主管）能不能改？④ 修改后是否留痕？

问题3：不同状态下的编辑权限矩阵

维度说明
现状台账有多个状态（待采集 / 采集进行中 / 待分析 / 分析中 / 已完成 / 已确认），但每个状态下各角色（录入人、责任人、确认人、管理员）能看什么、能改什么字段，没定义。
张会娟的要求"这个要写到开发说明里，开发才知道一进页面要不要开编辑模式。"
需要万工确认① 每个状态下，录入人/责任人/确认人分别有哪些操作权限？② 一进页面是否默认进入编辑模式？依据什么状态判断？③ 哪些字段在什么状态下变成只读？

问题4：多人录入时的"完成标记"与整体流转

维度说明
现状GRR等模块可能有多个录入人（如3个操作员），每个人录自己的数据。现在的"提交"是整体提交，但每个人录完自己的部分怎么标记？什么时候算全部录完？
张会娟的顾虑"有三个人的话你怎么办？每个人记录的数据没法记呀。"——如果只点一次整体提交，没法区分谁录完了、谁没录完。
张会娟的方案（暂定）每个人录完给自己的数据打标记，所有人都录完后系统自动判断整体状态完成。但"有没有必要做这个标记"她也不确定。
需要万工确认① 是否需要单人"完成标记"？② 全部人员录完后，系统是否自动触发"待分析"状态？③ 还是只要有一个人录完提交，整体就进入下一阶段？
对齐方式建议：高国翔把录入页原型截图发给万工，当面/线上确认以上4个问题，确认结论后写进对应页面的"开发备注-改动内容"里，再进入开发。
