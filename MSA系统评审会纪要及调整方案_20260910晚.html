一、完整会议纪要（业务逻辑梳理）

1. 计量器具台账

  • 在已确认字段基础上，台账只新增两个字段：“是否需做 MSA”（勾选）与“所属器具组”（下拉），其余字段维持现状。
  • 移除“是否样机”字段（万工：已勾选要做 MSA 就不必再判断组里做不做；样机概念在过审时难以解释）。器具组维护成员时也不再标注样机。
  • 器具组按型号维度划分（同规格/同厂家/同型号归一组）；MSA 评测周期维护在器具组层，不做单台器具维护（同型号不全检，只挑代表器具做 MSA）。
  • 器具组页面三合一：基础信息定义 + 评测周期/提前提醒周期设置 + 组内 MSA 执行履历查询；到期提醒推送到待办。

2. 被测参数（原质量特性维护）

  • 页面名正式更名“被测参数 / 被测项目”，避免与特殊特性清单、CP 概念混淆，降低审核解释成本。
  • 字段：被测参数编号、被测名称、计量/计数类型、适用检验方法（多选）、标准值、单位、上下限、零件名称/零件编号（产品特性）、工序（过程特性）、特性等级/SC·CC、工厂/车间。工厂/车间、特性等级暂不强制填写（预留扩展）。
  • 被测参数与计量器具（器具组）直接绑定，暂不强制关联零件/工序，但保留产品/过程特性扩展接口；每个被测参数可绑定多个分析方法及各自默认抽样规则，同一参数配多个器具组时可分别绑定。
  • 一期手工/导入维护，二期再关联 CP（控制计划）。

3. KAPPA 人员组

  • 单独建“卡帕人员组”，按岗位维度划分（IQC 检验员、IPQC、动总 GPR、电控 GPR、FQC 等），不以人名划分。
  • 用工号列表导入维护；做 KAPPA 任务时从岗位组内选具体执行人。
  • 周期/提醒规则与器具组一致，在器具组配置页面统一维护。

4. 样本库

  • 核心字段：样本编号、样本名称、样本类型（标准件/生产件）、对应被测项目、样本真值、有效期；去掉名义值/上下限等冗余字段。
  • 新增“日志查询”按钮：真值变更、效期变更自动记录操作人/操作时间/变更前后值，供审核追溯；评审流程不纳入线上（线下评审、系统留记录即可）。
  • MIC 任务选标准件后与样本编号自动关联，可反查履历。

5. MSA（MIC）计划

  • 创建动线：选被测参数 → 自动带出绑定的分析方法与器具组 → 勾选器具一键生成。
  • 任务两个来源：①周期任务由系统后台自动滚动生成（按器具组评测周期，提前一个月生成任务并推送待办，不在年初一次性建计划）；②临时任务（新增器具/维修后）手动创建，仅需填截止时间。
  • 同一器具组 + 同一被测参数下支持多台器具批量勾选，一次生成多个任务（较此前“单选量具”放宽）。
  • 线性 + 偏移同时勾选时默认合并为一个任务，共用一套取样数据（5 标准件 × 12 次 = 60 数据）出两份报告（AIAG 允许的合并，降成本）；仅选其一则单独生成。
  • 检验标准与质量特性（被测参数）做穿透关联，不再在创建页直接手选检验标准。

6. 数据录入

  • Excel 模板导入 + 页面直接录入并存。暂不开发设备数据自动抓取（无法区分点检/产品测/MIC 测，IQC 单独讨论）。
  • 导入由分析人在台账执行，操作员只能在线录入；录入的实测值允许修改。
  • GRR 按岗位选执行人（10 件 × 3 人 × 3 次）；线性/偏移先选标准件再录数据。

7. 结果展示

  • 每个分析任务独立结论（合格/不合格）；MSA 计划主台账展示各方法分项结论 + 总结论（任一分项不合格 → 总结论不合格）。
  • 结果页展示零部件/分析人/操作人/样本/关键结论。
  • 全部图表改为动态交互图（控制图、直方图、正态概率图、回归分析图，悬停出数值气泡）。
  • 报告输出格式对齐业务现有 Excel 模板。

8. 待确认/待推进（会议遗留）

  • 判读规则：业务方已发华为 MSA 指导书，需逐一核对各方法判读逻辑；线性规则最复杂，需专项确认；非结构化规则标记后单独对齐。
  • 操作指导书链接跳转：暂不纳入一期（使用频次低、逐特性绑定维护麻烦），二期全平台快捷搜索再议。
  • 可视化看板：周明鹏统筹，一期功能完成且有数据后评估；赶华为质量听证会/五星现场时先出报表雏形。
  • IQC 设备素材自动上传：单独讨论。

9. 排期

  • 本周输出 HTML 原型链接 → 下周二前业务全量字段确认 → 全面开发。
  • 功能优先交付，定制化报表延后 3–4 周，开发一个交付一个。
