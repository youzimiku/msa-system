2.2 线性/偏倚性分析报告逻辑报告

数据来源与分工：斜率、常量、P 值等核心统计值均由丁宁（后台程序）计算输出，前端仅负责接收与展示，不做二次计算。报告中「表头」部分由前端自行设计展示（评价人、日期等）。

核心三列：报告界面固定展示「部件号 / 参考值 / 测量数据」三列，对应丁宁数据中的「部件 / 参考值 / 响应（实测）」；并需提供估计方法选项设置。

术语对齐：参考值即标准值，由多次测量求平均得出；主水平 = 基准 = 样本库中的真值或参考值，需在样本录入时维护；「平均」指平均偏移值与平均 P 值（是一行的列名，不是单独字段）。

P 值数量：线性/偏倚在量程内选 5 个点，每个点输出各自 P 值，整体再有一个总 P 值（共 6 个），丁宁全部输出；张会娟需再与丁宁核对「平均 P 值」是否遗漏。

界面交互：图表需支持鼠标悬停交互，显示参考值等详细信息；前端界面只需要三列即可，不必展示多余列。

分析结果页 vs 报告：分析结果页不展示原始样本数据（样本有单独的页面/链接），但生成报告时必须把分析结果与样本数据合并展示（报告 = 表头 + 结论 + 统计值 + 图表 + 样本数据）。

偏移计算：偏移值（Offset）由前端按「实测值 - 参考值」自动计算（c2 - c1），保留负值、不要取绝对值、无需人工录入。

偏倚（单独偏移）：单独偏移没有图，只有数据 + 结果，使用单样本 T 检验；只有三个字段：主水平（参考值）、响应（实测值）、偏移。报告含表头 + 结论 + 中间显示值 + 直方图。

线性与偏移的关系：偏移是线性的附属产物，做线性时必须评估偏倚，没有单独的线性；线性偏移性合在一起展示。

2.3 GRR 分析调整GRR

评估方法：GRR 需支持「方差分析法」与「均值极差法」两种评估方法，前端提供选项；默认使用方差分析法。不同分析方法使用的评估方法不同（如均值极差法配标准差，方差分析法配 Xbar 类），代码需按分析方法做映射。

六图展示：GRR 报告包含均值图、极差图等六张图，丁宁已完成图表开发，前端按标准展示即可；报告还包括方差分量、量具评估值等（按 Minitab 标准）。

置信区间：报告需支持隐藏 95% 置信区间列；只支持 95% 置信区间，不支持 90% 等其他区间（要么看 95%，要么不看）。

报告行/列：报告表格行和列基本固定（量项目不变），值的部分变化；复制数据有 8 份（按命题宝格式）。

开发待办：高国翔需绘制 GRR 报告原型图（表头 + 结论 + 六图），检查是否有缺漏。

2.4 Kappa 分析补充Kappa
  • 样本规模：Kappa 采用生产件，样本量 20~50 件，默认配置为50 件 × 3 人 × 3 次；样本必须包含已知真值用于一致性比对（如 50 件中 40 件合格、10 件不合格）。
  • 交叉表：为确保程序排查准确性，Kappa 报告必须增加「交叉表」功能，统计检验员之间及检验员与标准之间的一致性数值。最终样式：以时阳阳群里发的版本为基础，再加入交叉表。
  • 判断：若只出矩阵，数据出错将无法排查；有了交叉表才能定位程序问题。
2.5 样本录入与权限管理录入

字段差异化：不同类型的分析需独立维护各自的样本录入字段，不能共用同一套录入界面。当前分为两套：GRR/Kappa 一套；线性、偏倚、稳定性、Cg/Cgk 一套（字段略不同，需逐项核对）。

偏倚性录入：录入界面需包含「人员」和「时间」字段，并支持自动计算偏移值；只显示需要的字段（如 P 值、偏移），不能多显示。

权限处理：建议通过筛选或权限控制管理操作员数据查看范围，避免用分页签（Tab）方式造成查看不便与权限处理啰嗦；权限上可直接隐藏对应数据页。

导入逻辑：导入数据在台账中统一处理，避免在录入界面做复杂 Sheet 页拆分。

2.6 其他杂项
  • 所有人（含元工_刘科壮）需安装 Minitab（命题宝）软件，用于后续测试数据验证。

会议二（11:21-12:21）：MSA 测量系统分析报表开发对齐

3.1 Kappa 交叉表结构与统计逻辑Kappa

交叉表本质：展示「基准值 × 实测值」的交叉统计数量，不是原始录入值。例如统计「基准值为 0（不合格）且实测值为 0」的数量。

字段定义统一：「标准值」字段统一更名为「基准值」，与「实测值」形成对应（基准值 = 标准值 = 样本库中的真值；Kappa 用 0=不合格、1=合格，也可用序列 12345）。

数据来源：交叉表中数值（数量）、Po、Pe、期望值等由丁宁后端计算，前端只负责展示。

阅读方式：一行一个人：总测量次数（如 30 次）、按基准值统计的数量（0 的数量 / 1 的数量）、实测值数量，中间为交叉值（实测 X 且基准 Y 的数量），最后汇总。

3.2 判定标准与结论输出判定

四个通用参数（不分组、每个项目可不同）：

参数阈值含义
一致性百分比≥ 90%评估一致性（好/差）
Kappa 值≥ 75%Fleiss Kappa 判定
误发（误判）率≤ 5%漏发/误发结论
漏发（漏判）率≤ 2%漏发/误发结论

结论归属：单项结论由前端做「比大小」判定（丁宁不给单项结论）；总体结论由丁宁输出（评估一致性 好/差）。

展示位置：报告必须展示判定标准（准则，客户审核需要）；分析结果页可显示可不显示。

3.3 Kappa 报告的三组 + 汇总结构结构
  • 组一 · 检验员自身（单个检验员）：评估一致性 + Fleiss Kappa。
  • 组二 · 每个检验员与标准：评估一致性 + 不一致性 + Fleiss Kappa（比组一多「不一致性」）。
  • 组三 · 检验员之间：两两组合（A-B、A-C、B-C，人越多组合越多），只展示必要项（两组数据）。
  • 汇总：检验自身、检验之间、来源于标准、所有来源于和标准，共四种情况的汇总结论，放报告前面方便直接看结论。
  • 每个维度（每组）都会有「好/差」结论；最终总体结论按「评估一致性」走。
3.4 Cg/Cgk 报表字段清单Cg/Cgk

必显核心参数：Rg（极差）、N（总数）、Sigma（标准差）、6 Sigma（六西格玛）、Cg、Cgk。

辅助信息：名义尺寸/基准值、实测值、分辨率、领用人、基础号（工位）；表格编号、名称、精度（分辨率）。

剔除冗余：±3 倍西格玛、0.2T、重复的「单位」字段均剔除。

术语：「标准值」统一改为「基准值」；「名义尺寸」即被测参数的标准值/基准值。

3.5 稳定性分析（SPC）集成方案稳定性

功能复用：直接复用现有 SPC 控制图查看功能，不再单独开发新界面。在台账页面点击「结论 / 查看详情」时，直接调用现有 SPC 控制图查看页面。

界面精简：调用 SPC 页面时需隐藏顶部操作按钮（编辑、删除等）及状态栏，仅保留图表展示区域和底部判异规则说明；去掉「刘关张」弹窗及相关红点提示（保留点选交互）。

报告输出：稳定性报告需包含「控制图」和「直方图」，附带统计量数据；若数据量大可分页展示（一页图、一页数据）；报告最前端明确展示「受控 / 不受控」总体结论。

结论位置：计划生成的图号里带「受控 / 不受控」结论；SPC 页面底部判异规则说明保留（当前只用「单点超出上下限」一个规则）。

台账关系：稳定性台账单独做，不能直接用 SPC 的台账（两者不是一回事）。

会议三（12:01-13:01）：SPC 与 MSA 系统数据录入逻辑对齐

4.1 SPC 控制图判异规则与交互删减SPC
  • 判异规则：走自定义规则（当前只用「单点超出上下限」），不照搬国标全部规则（连续 6 点同侧等暂不用，后续可能增加）；后台算出的结果前端直接展示。
  • 计算归属：控制图结果由「小娜」后台计算输出，前端只取结果展示。
  • 弹窗去除：去除「刘关张」弹窗功能及相关红点提示，仅保留必要的点选交互；图上的点可点击做功能的部分也要去掉。
4.2 MSA 稳定性分析数据表重构表结构
  • 重建样本录入表：参照「计量样本录入」界面表结构，新建 MSA 稳定性样本录入表；禁止直接使用原表名（如 ESP 结构），需重新命名（复制一个，改表名）。
  • 控制图编号：样本录入阶段不显示；提交分析时从配置表获取并传给丁宁（计算号），作为唯一标识。
  • 录入字段：样品号（可一个或多个，如 1~3 件）、测量人、日期时间、子组号、实测值（每组最多到 10 个值）；所有测量都加日期时间和人。
4.3 子组（Subgroup）逻辑与录入参数子组

子组概念：相近时间、相同生产条件下产出的多个数据点（如一个工位打 4 个螺丝取均值作为一组）；在 MSA 稳定性中可理解为「测量次数」。

录入参数扩展：稳定性录入界面增加「子组数」和「组内测量次数」两个参数（加上原有样本数、人员数量、次数，共 4 个参数）：

  • 单值模式：不需要填组内测量次数，表格中一个值即可。
  • 子组模式：需填写组数及每组内的测量值个数（如 4 个角各测一次 → 组内 4 个值），子组数展开成队列。

数据完整性：子组号必须连续、不允许缺失，系统根据设定的子组数自动生成序列（1~N），不允许手填跳号。

统一结论与术语口径

6.1 统一结论
  • 报告统计值（斜率、常量、P 值、Po、Pe、期望值、交叉表数值、SPC 判异结果）一律由丁宁后台 / 小娜后台计算输出，前端只做接收、展示与「比大小」式单项判定。
  • 「标准值」字段统一更名为「基准值」；参考值 = 标准值 = 多次测量平均值；主水平 = 基准 = 样本库真值/参考值。
  • 偏倚（偏移）值 = 实测值 − 参考值，前端自动计算，保留负值，不取绝对值。
  • 各分析方法样本录入字段独立维护（GRR/Kappa 一套；线性/偏倚/稳定性/Cg/Cgk 一套），导入在台账统一处理，权限用筛选/权限控制而非分页签。
  • Kappa 判定四参数通用：一致性 ≥ 90%、Kappa ≥ 75%、误发 ≤ 5%、漏发 ≤ 2%；单项结论前端判定，总体结论丁宁输出；报告必须含判定标准，分析结果页可隐藏。
  • 稳定性分析复用 SPC 控制图页面（隐藏按钮与状态栏，保留图表 + 判异规则说明），报告 = 控制图 + 直方图 + 统计量 + 受控/不受控结论。
  • MSA 稳定性样本录入表参照 SPC 计量样本录入表重建（改表名），增加子组数、组内测量次数参数，子组号连续不缺失。
