二、页面骨架

每个业务页面从上到下遵循：

  • 页面头（.page-head）：左侧页面标题 16px 加粗 + 副标题灰色说明；右侧放主操作按钮（如「+ 创建 MSA 计划」）。
  • 查询条件卡片（.panel）：白色圆角卡片，内放筛选字段（工厂/车间/关键词/状态等），字段一行排列；按钮（查询/重置）另起一行放在查询条件下方，不与筛选框同行。
  • 列表卡片（.panel）：标题栏左侧带蓝色竖条 4×16px + 标题 16px 加粗；右侧放操作按钮组（新增/导入/导出）。卡片内为 Ant Design Table，底部分页。
按钮必须另起一行：查询条件一行排完后，下一行放「查询」「重置」按钮，不要挤在筛选框同一行。

4.2 数据录入矩阵（五个录入数据页）

这是特殊表格，样式与普通列表不同：

  • 表格容器 padding 为 0，撑满白色面板，不留外间距。
  • 表头背景 #ACCDEC（浅蓝），无圆角。
  • 单元格背景 #D8E8F6（淡蓝）。
  • 所有圆角归零（表头、输入框、容器）。
  • 完整网格线：横向行线 + 纵向列线，浅灰细实线 #e2e8f0。
  • 左侧台账卡片列表 + 右侧录入矩阵，左右分栏布局。

八、报告页面布局

五个报告页（GRR/KAPPA/线性偏倚/CgCgk/稳定性）结构统一：

  • 结论横幅：绿色（可接受）/ 橙色（有条件）/ 红色（不可接受）背景条，带边框。
  • 报告表头：Descriptions 描述列表，两列布局，含报告编号/计划号/器具/参数/日期等。
  • KPI 指标行：横向排列关键统计值（如 X̄/R/UCL/LCL/Cg/Cgk），每项标签灰色 12px + 数值加粗 16px。
  • 图表区：双列并排（如 X 控制图 + R 控制图），白底卡片，坐标系浅灰网格线，控制限红色虚线，中心线绿色实线。
  • 统计表：Ant Design Table 或纯 .mono-grid 等宽字体表格，完整网格线。
  • 原始数据：底部数据明细表，等宽字体显示测量值。

十二、通用规则

  • 所有页面统一使用 Ant Design 组件库。
  • 表格操作列按钮文字按钮为主，删除用红色文字按钮。
  • 删除、升版等危险操作必须二次确认弹窗。
  • 开发备注模块（黄色背景提示条）仅在原型阶段保留，正式开发移除。
  • 页面间跳转通过左侧菜单切换，不使用浏览器前进后退。
  • 所有弹窗/抽屉内容超高必须出滚动条，不允许溢出。
  • 空数据显示「暂无」或「-」，不显示 undefined/null。
  • 修改参数后需刷新页面验证不白屏，再推送。
